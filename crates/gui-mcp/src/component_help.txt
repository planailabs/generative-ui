Generative UI components — pass `components_json` to publish_surface as a JSON **string**
containing an array of nodes, each `{ "type": "<name>", ...fields }`. Nesting uses a
`children` array. (It is a string, e.g. "[{\"type\":\"heading\",\"text\":\"Hi\"}]".)

heading   { "type": "heading", "text": "...", "level": 1-3 (default 2) }
text      { "type": "text", "text": "..." }
button    { "type": "button", "label": "...", "action": "act", "value": <any> }
            Clicking sends a backflow event with this action and value.
input     { "type": "input", "name": "field", "label": "...", "placeholder": "...", "input_type": "text|email|number|..." }
select    { "type": "select", "name": "field", "label": "...",
            "options": [ { "value": "v", "label": "V" }, ... ] }
checkbox  { "type": "checkbox", "name": "field", "label": "...", "checked": false }
card      { "type": "card", "children": [ ...nodes... ] }
form      { "type": "form", "action": "submit_act", "children": [ ...inputs... ] }
            Renders a submit button; submitting sends one backflow event whose value is an
            object of all child input names → values.
link      { "type": "link", "to": "surface-slug", "label": "..." }
            Navigates to a sibling surface in the same deck.
deck-nav  { "type": "deck-nav" }   Prev/next navigation chrome for the deck.
html      { "type": "html", "html": "<raw/>" }   Raw HTML escape hatch.

Interaction flows back via wait_for_backflow / list_backflow:
  - a button yields { action, value }
  - a form yields  { action: "<form action>", value: { field: value, ... } }
